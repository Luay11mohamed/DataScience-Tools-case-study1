this code contains ui using Streamlit 
in order to run the final ui interface : 
1) save the code as ds_app3.py for example and run after downloading the full libraries
2) save a copy of the code file in documents file in the C user for an example
3) open CMD and type :cd Documents
4) then type : python -m streamlit run ds_app3.py
5) a web host opens automaticaly and the final ui is shown on a created website
